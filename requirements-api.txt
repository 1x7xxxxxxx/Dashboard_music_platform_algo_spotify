# Dependencies of the FastAPI image ONLY — see Dockerfile.api.
#
# Why this file exists
# --------------------
# One `requirements.txt` was installed into every image. The API — which serves
# JSON — was therefore carrying, measured in production on 2026-08-30:
#
#     454 MB  nvidia-nccl-cu12   (CUDA collective comms, on a CPU-only VPS)
#     228 MB  xgboost
#     188 MB  plotly
#     173 MB  llvmlite  (+ 35 MB numba, via shap)
#      97 MB  googleapiclient
#      50 MB  sklearn,  32 MB skimage (via lime),  36 MB matplotlib
#
# None of it reachable from `src.api.main`. That was verified, not assumed: the
# module was imported inside the running production container with every one of
# those packages blocked by a `sys.meta_path` hook, and it imported clean.
# `tests/test_the_api_image_carries_only_what_the_api_imports.py` is that same
# proof, kept runnable so the claim cannot quietly stop being true.
#
# What must stay, and why it looks odd
# ------------------------------------
# `streamlit` is here on purpose. `src/api` reaches `get_db_connection()` in
# `src.dashboard.utils`, which imports streamlit at module scope. Removing it means
# untangling that dependency first — a separate change, with its own risk. Naming
# the reason is what stops the next reader from "cleaning it up" and breaking prod.
