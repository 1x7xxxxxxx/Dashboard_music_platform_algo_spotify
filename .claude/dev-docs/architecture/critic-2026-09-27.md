verdict retenu, pour que le code écrit ensuite se relise contre lui.

- d) cible de charge avec seuil ADR-007 — **BUILD**.

- f) taille de pool + ADR-030 — **BUILD-MODIFIED** : nommer le pool (pool psycopg2 du dashboard ≠
  pools Airflow) ; les pools Airflow par plateforme se dimensionnent sur les limites d'API.
