Getting started with streaMLytics — API & CSV

This guide covers both data sources: (1) the API connectors, to fill in on the « API Credentials » page, and (2) CSV file import, via the « Add my numbers » page. The outline below lists the platforms covered.

By the end of this guide you will have:
  • your accounts connected, and data arriving every night without you coming back to it;
  • your Spotify and Apple listens visible on the dashboard;
  • what you need to tie promo spend to the listens it produces.

Part 1 — API connectors

Spotify

One single value to paste: the link to your Spotify Artist page.

1. On Spotify, open your artist page, then click the ••• button — the three dots, to the right of the Follow / Following button.
The ••• button → Share → Copy link to artist
2. In the menu that opens: Share → Copy link to artist.
3. Paste the link into the Spotify Artist ID or profile URL field, then Save. We extract the ID automatically — no need to cut it up.

The values to paste:

  • Spotify Artist ID or profile URL
    paste the full URL of your artist page — we extract the id
    e.g. https://open.spotify.com/artist/3TVXtAsR1Inumwj472S9r4 — sample format, do not copy it
Open the Spotify portalTest the connection in streaMLytics

YouTube

2 values to grab: the API key (YouTube Data API v3) and your channel ID.

1. At console.cloud.google.com/apis/dashboard, create (or select) a project, then click + Enable APIs and services.
APIs & services → Enable APIs
2. In the API Library, search for YouTube Data API v3.
Library → search the API
3. Click the YouTube Data API v3 result.
Select the API
4. Click Enable; the product page should show API enabled.
API enabled
5. Go to Credentials → Create credentials → API key, then Show key and copy it.
Credentials → API key → Show key
6. Get the Channel ID: at youtube.com/account_advanced → Channel ID → Copy (starts with UC…).
YouTube → Advanced settings → Channel ID
7. Paste the API key + the Channel ID into API Credentials → YouTube.

The values to paste:

  • API Key 🔒
    starts with 'AIza', ~39 characters
    e.g. AIzaSyA1B2c3D4e5F6g7H8i9J0kLmNoPqRsTuVwX — sample format, do not copy it
  • Channel ID
    starts with 'UC', 24 characters
    e.g. UC_x5XG1OV2P6uZZ5FSM9Ttw — sample format, do not copy it

Note — Free quota ~10,000 units/day; exceeding it returns 403 (temporary).

Open the YouTube portalTest the connection in streaMLytics

SoundCloud

A single thing to provide: the link to your SoundCloud profile. We derive your identifier from it; streams and followers are then collected automatically.

1. Open your SoundCloud profile and copy the address shown in the browser bar — it looks like https://soundcloud.com/your-name.
2. Paste that link into API Credentials → SoundCloud, then Save. Your User ID is looked up automatically and shown back to you as confirmation.

The values to paste:

  • SoundCloud profile
    your page link; the numeric User ID is derived from it
    e.g. https://soundcloud.com/your-name — sample format, do not copy it
Open the SoundCloud portalTest the connection in streaMLytics

Meta / Instagram

Meta is configured at the platform level (shared app). You provide only your Ad Account ID; the token, the app and Instagram are managed by the administrator.

1. Open the portal above and sign in. If you manage several ad accounts, pick the one you want to track first: that is the one the address will name.
2. Simplest: copy the whole address. Click your browser's address bar (at the very top), copy all of it, and paste it as-is — we extract the account number from it. adsmanager.facebook.com/adsmanager/manage/campaigns?act=123456789012345&business_id=… If you would rather paste the number only, take the one right after act=, stopping at the &. With or without the act_ prefix, both work: act_123456789012345 and 123456789012345 are accepted identically.
The number after act= in the address bar
3. Don't confuse it with business_id=… (your Business Manager) or an ad set ID: only the number after act= is correct.
4. Required, and it is yours to do. Until this account is shared, collection sees nothing — even with the right ID. Open Business Manager → Apps and look for ETL_DASHBOARD_SPOTIFY — that is the name our application goes by on Meta; if it is not in the list, ask us to add it. Then, in Ad accounts → Add people / apps, pick yours and grant Analyst (or Advertiser) permission.
5. Paste the value into the Ad Account ID field, then Save — the connection is tested right after. A here almost always points back to the sharing step above.
6. Instagram (optional but recommended). To track followers and posts we need the Instagram Business Account ID — not your @handle. Open Meta Business Suite → Settings → Accounts → Instagram accounts, select your account: the numeric ID is shown under the name. Paste it into Instagram Business Account ID.
7. Instagram prerequisite: the account must be a Business or Creator account (not personal) linked to a Facebook Page. A personal account returns no statistics through the API.

The values to paste:

  • Ad Account ID (act_… or numeric)
    the full Ads Manager URL works too — `act_1234567890` and `1234567890` are accepted identically
    e.g. act_1234567890 — sample format, do not copy it
  • Instagram Business Account ID
    optional — ~17 digits, for Instagram stats
    e.g. 17841400000000000 — sample format, do not copy it
Open the Meta / Instagram portalTest the connection in streaMLytics

Part 2 — CSV file import

Spotify for Artists

3 file types to export, all with the « 12 months » filter. For N tracks you get N + 2 files (N timelines + 1 summary + 1 audience). Example: 11 tracks → 13 files.

1. Sign in at artists.spotify.com and open the Music tab (disc icon, left sidebar).
Sidebar → Music tab
2. Click the Songs sub-tab.
Music → Songs
3. Open Filters and set the period to 12 months.
Period filter → 12 months
4. Click the download icon (↓) left of the filter: you get the …-songs-1year.csv summary (listeners, streams, saves, release date per song).
Download the songs summary
5. For per-track timelines: in the list, open a song (click its row).
Song list → open a song
6. On the song page, set the filter to 12 months then click download (↓): <song>-timeline.csv (daily streams). Repeat for each song.
Song page → 12 months → download
7. Open the Audience tab (audience icon, left sidebar).
Sidebar → Audience tab
8. On Overview, 12 months filter, click download (↓): …-audience-timeline.csv (artist-level listeners/streams/followers).
Audience → Overview → download
9. Do not use the « All time » filter for the summary: Spotify returns 0 listeners and saves there. The …-songs-all.csv file is also rejected on import.
FileExpected nameColumns
Per-track timeline<song>-timeline.csvdate, streams
Songs summary (12 months)…-songs-1year.csvsong, listeners, streams, saves, release_date
Audience…-audience-timeline.csvdate, listeners, streams, followers, playlist adds, saves

Apple Music for Artists

Apple Music for Artists has no API: the per-song performance CSV export is the only source (a single file). Make sure to set the period to All Time for a complete history. FR and EN headers are both recognized.

1. Sign in at artists.apple.com, pick your artist, then on the Overview tab set the period selector (top right) to All Time.
Overview → period → All Time
2. Click the Music tab.
Music tab
3. In the Songs section, click See All (top right).
Songs → See All
4. Click the download icon (↓, top right): you get songs_….csv (Song, Plays, Avg. Listeners, Shazams, Radio Spins, Purchases).
Download the CSV

Per-song performancesongs_….csvMorceau / Song Title, Écoutes / Plays, Auditeurs / Listeners (opt.)

iMusician (distributor)

Two report types, requested per year (iterate over every year of your catalogue): the release summary (monthly totals per release) and the sales report (detail per ISRC/shop/country). The importer auto-detects each type.

1. Revenue tab (sidebar) → Reports → click Download report (top right).
Revenue → Reports → Download report
2. Period Year, select a year, type Release summary, then Request report. Repeat for each year.
Year → year → Release summary → Request
3. Do it again choosing Sales report (for each year as well).
Year → year → Sales report → Request
4. Account tab → Downloads: download (↓) all the generated yearly reports (summaries + sales).
Account → Downloads → download all
FileExpected nameColumns
Release summary*.csvStatement date, Release title, Track streams, Total revenue
Sales report*.csvSales date, ISRC, Shop, Revenue EUR

DistroKid (distributor)

A single export covers your whole history: the detailed Bank report (one row per platform × title × country × month, amounts in USD — the USD→EUR conversion rate is set at import time). Format .tsv or .csv, both are auto-detected.

1. Sign in at distrokid.com → Bank menu — that's your earnings page.
2. At the bottom of the page, click « SEE EXCRUCIATING DETAIL » — the full row-by-row breakdown.
3. Click Download to get the file. Above 50,000 rows, DistroKid asks you to filter (period / platform / release) before generating the export — repeat as needed.
4. Import the file here as-is (.tsv or .csv) and adjust the suggested USD→EUR rate before confirming.
