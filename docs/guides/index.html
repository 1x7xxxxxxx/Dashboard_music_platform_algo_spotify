Démarrer avec streaMLytics — API & CSV

Ce guide couvre les deux sources de données : (1) les connecteurs API, à renseigner dans la page « Credentials API », et (2) l'import des fichiers CSV, via la page « Ajouter mes chiffres ». Le sommaire ci-dessous liste les plateformes couvertes.

À la fin de ce guide, vous aurez :
  • vos comptes connectés, et de la donnée qui arrive chaque nuit sans que vous ayez à y revenir ;
  • vos écoutes Spotify et Apple visibles dans le tableau de bord ;
  • de quoi relier ce que vous dépensez en promo à ce que ça produit en écoutes.
  1. Partie 1 — Connecteurs API
    • SoundCloud
    • Spotify
    • YouTube
    • Meta / Instagram
  2. Partie 2 — Import des fichiers CSV
    • Spotify for Artists

Partie 1 — Connecteurs API

SoundCloud

1. Ouvrez votre profil SoundCloud et copiez l'adresse affichée dans la barre du navigateur — elle ressemble à https://soundcloud.com/votre-nom.
2. Collez-le dans Saisir tes identifiants, la colonne de gauche, puis Enregistrer.

Les valeurs à coller :

  • Profil SoundCloud
    le lien de votre page — rien à découper
    ex. https://soundcloud.com/votre-nom — exemple de forme, ne le copie pas
Ouvrir le portail SoundCloudTester la connexion dans streaMLytics

Spotify

1. Clique le bouton ••• sur ta page artiste.
Le bouton ••• → Partager → Copier le lien vers l'artiste
2. Partager → Copier le lien vers l'artiste.
3. Colle le lien ⬅ dans URL profil artiste.

Les valeurs à coller :

  • URL profil artiste
    colle l'URL complète de ta page artiste — on extrait l'ID
    ex. https://open.spotify.com/artist/3TVXtAsR1Inumwj472S9r4 — exemple de forme, ne le copie pas
Ouvrir le portail SpotifyTester la connexion dans streaMLytics

YouTube

Côté artiste : une seule valeur — ton Channel ID (commence par UC…). La clé API est partagée (gérée par l'admin), tu n'as pas à en créer. Saute directement à l'étape Channel ID ci-dessous. (Les étapes 1→5 ne concernent que l'admin, une seule fois, s'il met en place sa propre clé.)

1. (Admin, une fois) Sur console.cloud.google.com/apis/dashboard, créez d'abord un projet (le bouton Activer les API reste grisé tant qu'aucun projet n'existe), puis cliquez + Activer les API et les services.
API et services → Activer les API
2. Dans la Bibliothèque d'API, recherchez YouTube Data API v3.
Bibliothèque → rechercher l'API
3. Cliquez sur le résultat YouTube Data API v3.
Sélection de l'API
4. Cliquez Activer ; la page produit doit afficher API activée.
API activée
5. Allez dans Identifiants → Créer des identifiants → Clé API, puis Afficher la clé et copiez-la.
Identifiants → Clé API → Afficher la clé
6. Récupérez le Channel ID : sur youtube.com/account_advanced → ID de la chaîne → Copier (commence par UC…).
YouTube → Paramètres avancés → ID de la chaîne
7. Collez la clé API + le Channel ID dans Credentials API → YouTube.

Les valeurs à coller :

  • API Key 🔒
    commence par 'AIza', ~39 caractères
    ex. AIzaSyA1B2c3D4e5F6g7H8i9J0kLmNoPqRsTuVwX — exemple de forme, ne le copie pas
  • Channel ID
    commence par 'UC', 24 caractères
    ex. UC_x5XG1OV2P6uZZ5FSM9Ttw — exemple de forme, ne le copie pas

Note — Quota gratuit ~10 000 unités/jour ; un dépassement renvoie 403 (temporaire).

Ouvrir le portail YouTubeTester la connexion dans streaMLytics

Meta / Instagram

Meta est configuré au niveau de la plateforme (app partagée). Vous fournissez uniquement votre Ad Account ID ; le token, l'app et Instagram sont gérés par l'administrateur.

1. Ouvre le portail ci-dessus et connecte-toi. Si tu gères plusieurs comptes publicitaires, sélectionne d'abord celui que tu veux suivre : c'est lui que l'adresse va nommer.
2. Le plus simple : copie l'adresse entière. Clique dans la barre d'adresse de ton navigateur (tout en haut), copie tout, et colle-le tel quel — on en extrait le numéro de compte. adsmanager.facebook.com/adsmanager/manage/campaigns?act=123456789012345&business_id=… Si tu préfères ne coller que le numéro, prends celui qui suit act= et s'arrête au &. Avec ou sans le préfixe act_, les deux marchent : act_123456789012345 et 123456789012345 sont acceptés à l'identique.
Le nombre après act= dans la barre d'adresse
3. Ne confondez pas avec business_id=… (votre Business Manager) ni avec un ID d'ensemble de publicités (ad set) : seul le nombre après act= est le bon.
4. Étape indispensable, et c'est vous qui la faites. Tant que ce compte n'est pas partagé, la collecte ne verra rien — même avec le bon ID. Ouvrez Business Manager → Applications et cherchez ETL_DASHBOARD_SPOTIFY — c'est le nom sous lequel notre application apparaît chez Meta ; si elle n'est pas dans la liste, demandez-nous de vous l'ajouter. Puis, dans Comptes publicitaires → Ajouter des personnes / des applications, sélectionnez le vôtre et donnez-lui l'autorisation Analyste (ou Annonceur).
5. Colle la valeur dans le champ Ad Account ID, puis Enregistrer — la connexion est testée dans la foulée. Un ici pointe presque toujours vers l'étape de partage ci-dessus.
6. Instagram (optionnel mais recommandé). Pour suivre vos followers et vos posts, il faut l'ID du compte Instagram Business — pas votre @pseudo. Ouvrez Meta Business Suite → Paramètres → Comptes → Comptes Instagram, sélectionnez votre compte : l'ID numérique est affiché sous le nom. Collez-le dans le champ Instagram Business Account ID.
7. Prérequis Instagram : le compte doit être en Business ou Créateur (pas personnel) et être relié à une Page Facebook. Un compte personnel ne renvoie aucune statistique via l'API.

Les valeurs à coller :

  • Ad Account ID (act_… ou numérique)
    l'URL entière du Gestionnaire de publicités convient aussi — `act_1234567890` et `1234567890` sont acceptés à l'identique
    ex. act_1234567890 — exemple de forme, ne le copie pas
  • Instagram Business Account ID
    optionnel — ~17 chiffres, pour les stats Instagram
    ex. 17841400000000000 — exemple de forme, ne le copie pas
Ouvrir le portail Meta / InstagramTester la connexion dans streaMLytics

Partie 2 — Import des fichiers CSV

Spotify for Artists

3 types de fichiers à exporter, tous avec le filtre « 12 mois ». Pour N titres, vous obtenez N + 2 fichiers (N timelines + 1 résumé + 1 audience). Exemple : 11 titres → 13 fichiers.

1. Connectez-vous sur artists.spotify.com et ouvrez l'onglet Musique (icône disque, barre latérale gauche).
Barre latérale → onglet Musique
2. Cliquez sur le sous-onglet Titres.
Musique → Titres
3. Ouvrez Filtres et réglez la période sur 12 mois.
Filtre Période → 12 mois
4. Cliquez sur l'icône de téléchargement (↓) à gauche du filtre : vous obtenez le résumé …-songs-1year.csv (auditeurs, streams, sauvegardes, date de sortie par titre).
Télécharger le résumé titres
5. Pour les timelines par titre : dans la liste, ouvrez un titre (clic sur la ligne du morceau).
Liste des titres → ouvrir un titre
6. Sur la page du titre, réglez le filtre sur 12 mois puis cliquez sur téléchargement (↓) : <titre>-timeline.csv (streams quotidiens). Répétez pour chaque titre.
Page d'un titre → 12 mois → télécharger
7. Ouvrez l'onglet Public (icône audience, barre latérale gauche).
Barre latérale → onglet Public
8. Sur Vue d'ensemble, filtre 12 mois, cliquez sur téléchargement (↓) : …-audience-timeline.csv (auditeurs/streams/followers au niveau artiste).
Public → Vue d'ensemble → télécharger
9. N'utilisez pas le filtre « Depuis le début » pour le résumé : Spotify y renvoie auditeurs et sauvegardes à 0. Le fichier …-songs-all.csv est d'ailleurs rejeté à l'import.
FichierNom attenduColonnes
Timeline par titre<titre>-timeline.csvdate, streams
Résumé titres (12 mois)…-songs-1year.csvsong, listeners, streams, saves, release_date
Audience…-audience-timeline.csvdate, listeners, streams, followers, playlist adds, saves

Apple Music for Artists

Apple Music for Artists n'a pas d'API : l'export CSV de la performance par morceau est la seule source (1 seul fichier). Réglez bien la période sur Depuis le début pour un historique complet. En-têtes FR et EN reconnus.

1. Connectez-vous sur artists.apple.com, sélectionnez votre artiste, puis sur l'onglet Aperçu réglez le sélecteur de période (en haut à droite) sur Depuis le début.
Aperçu → période → Depuis le début
2. Cliquez sur l'onglet Musique.
Onglet Musique
3. Dans la section Morceaux, cliquez sur Tout afficher (en haut à droite).
Morceaux → Tout afficher
4. Cliquez sur l'icône de téléchargement (↓, en haut à droite) : vous obtenez songs_….csv (Morceau, Écoutes, Moy. d'auditeurs, Shazam, Radio Spins, Achats).
Télécharger le CSV
FichierNom attenduColonnes
Performance par morceausongs_….csvMorceau / Song Title, Écoutes / Plays, Auditeurs / Listeners (opt.)

iMusician (distributeur)

Deux types de rapports, à demander par année (itérez sur toutes vos années de catalogue) : le résumé par sortie (totaux mensuels par release) et le rapport de ventes (détail par ISRC/shop/pays). L'import détecte chaque type automatiquement.

1. Onglet Revenus (barre latérale) → Rapports → cliquez sur Télécharger le rapport (en haut à droite).
Revenus → Rapports → Télécharger le rapport
2. Période An, sélectionnez une année, type Résumé par sortie, puis Demander le rapport. Répétez pour chaque année.
An → année → Résumé par sortie → Demander
3. Refaites l'opération en choisissant Rapport de ventes (pour chaque année également).
An → année → Rapport de ventes → Demander
4. Onglet Compte → Téléchargements : téléchargez (↓) tous les rapports annuels générés (résumés + ventes).
Compte → Téléchargements → tout télécharger
FichierNom attenduColonnes
Résumé par sortie*.csvStatement date, Release title, Track streams, Total revenue
Rapport de vente*.csvSales date, ISRC, Shop, Revenue EUR

DistroKid (distributeur)

Un seul export couvre tout votre historique : le rapport détaillé de la Bank (une ligne par plateforme × titre × pays × mois, montants en USD — le taux de conversion USD→EUR se règle au moment de l'import). Format .tsv ou .csv, les deux sont reconnus automatiquement.

1. Connectez-vous sur distrokid.com → menu Banque (« Bank » si le compte est en anglais) — c'est la page de vos revenus.
2. En bas de la page, cliquez sur « Voir dans le moindre détail » (« SEE EXCRUCIATING DETAIL » en anglais) — le détail complet ligne par ligne.
3. Cliquez sur Download pour télécharger le fichier. Au-delà de 50 000 lignes, DistroKid demande de filtrer (période / plateforme / release) avant de générer l'export — répétez si besoin.
4. Importez le fichier ici tel quel (.tsv ou .csv) et ajustez le taux USD→EUR proposé avant de confirmer.
FichierNom attenduColonnes
Bank details (détail des revenus)*.tsv / *.csvSale Month, Store, Title, ISRC, Quantity, Earnings (USD)
